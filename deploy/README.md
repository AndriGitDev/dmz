# Community deployment and distribution

Active direction: [ADR 0005](../docs/adr/0005-free-community-project.md). Shield executes locally; the public static website is maintained in `AndriGitDev/dmz-web`. No Portal/Gateway service, hosted inference or tenant vault is offered.

Do not provision the dormant hosted scaffold as part of the community transition. If hosted work is explicitly revived, ADR 0004 requires verified deployment boundaries (initially Hetzner Germany/Finland), model routes, retention and metadata-only audit. The former universal Iceland-hosting/only-pseudonyms description is superseded.

For preview packages use the [distribution checklist](../docs/community-distribution.md). Do not publish private models, datasets or benchmark artifacts through the website build. Keep production website release evidence separate from extension/store release evidence.
