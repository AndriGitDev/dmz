# Security

Report vulnerabilities privately to **andri@kastro.is**. Include the affected version or source commit, impact and minimal reproduction using fabricated data. Never include real prompts, personal data, credentials or customer logs. Do not disclose an unfixed vulnerability in a public issue. No response deadline or supported-version guarantee is promised.

dmz is alpha software. Detection is incomplete, failures warn and continue sending, attachments remain unchanged, and the host website can see the original draft before masking. Source availability is not proof of safety.

## Release identity

Use source and release links from https://dmz.is and https://github.com/AndriGitDev/dmz (website: https://github.com/AndriGitDev/dmz-web). For a published package, compare the version, source identity and SHA-256 with the maintainer's release record. A matching checksum proves agreement with that record, not independent security. Review source changes before building a fork. A copied name or logo does not establish maintainer approval.

GPL licensing does not prevent malicious behavior. Modified distributions must satisfy the license, including applicable notices and corresponding-source obligations. Do not imply that an independently modified build is an official release.
