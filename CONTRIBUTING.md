# Contributing to dmz

Review the README, repository instructions and current product specification before changing behavior. Small fixes, accessibility improvements, translations, synthetic regression cases and security review are welcome. Explain the problem and the checks run in each pull request.

Contributions to original project code are accepted under GPL-3.0-only. Submit only work you have the right to license. Keep upstream attribution and license notices intact. Identify changes to third-party material and document any added dependency's license.

Use fabricated examples only. Never submit real prompts, customer records, personal identifiers, secrets, credentials or licensed source datasets. Synthetic kennitölur use century digit `8`. Do not attach private scanner assets, raw training data or full challenge material. Public detector results must retain their evaluation limitations.

Report vulnerabilities privately as described in [SECURITY.md](SECURITY.md). Use ordinary issues for non-sensitive bugs; include a reproducible synthetic example and environment details.

The product is **dmz**, the Chromium extension. Keep Icelandic and English website content in sync. Do not add accounts, telemetry, hosted processing or new product promises as part of a routine fix.
