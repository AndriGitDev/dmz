# Current implementation coverage

See [product specification](product-spec.md), [roadmap](roadmap.md) and [publication readiness](open-source-readiness.md).

The implemented product is dmz, the Chromium extension. It has device-local masking, visible markers, per-tab mapping and local restoration on selected site paths. Basic and trained builds differ. Failures warn and continue, attachments remain unchanged and the host page can observe original drafts. Independent detector validation is incomplete.

Source is prepared under GPL-3.0-only. Public availability, third-party rights and release reproducibility require evidence; see [open decisions](open-decisions.md).
