# dmz release checklist

- [ ] Complete [source publication readiness](open-source-readiness.md) for both repositories.
- [ ] Record exact source commit, build profile, version and artifact checksums.
- [ ] Verify upstream code/model/data rights and retain all notices.
- [ ] Run detector, scanner and browser checks appropriate to the actual package.
- [ ] Test installation, updates, local restoration, pause, reset and removal with fabricated data.
- [ ] Verify bilingual website links and disclosures on the deployed build.
- [ ] Confirm operator identity, hosting logs, contact retention and store disclosures.
- [ ] Obtain independent detector validation before stronger quality claims; retain current limitations.
- [ ] Provide corresponding source and release notes for distributed GPL-covered binaries.

Existing alpha artifacts remain distinct from later source changes. See [distribution](community-distribution.md) and [quality contract](detector-quality-contract.md).
