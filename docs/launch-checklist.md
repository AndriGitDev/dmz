# Community release checklist

Active direction: [ADR 0005](adr/0005-free-community-project.md), 27 October 2026. Completed source changes and local verification are separate from deployment and extension release acceptance.

## Scope transition

- [x] Define free local Shield, optional separate Kastro assistance and deferred Portal/Gateway.
- [x] Replace paid-pilot/revenue continuation gates with community usability, quality and maintenance checks.
- [x] Update both website locales, old price/pilot/product URLs, metadata, canonical links and feedback guidance in source.
- [x] Align extension description/settings, private alpha instructions and Kastro's current free-tools presentation.
- [x] Preserve security/Coolify updates, privacy baseline and private detector disclosure.
- [x] Run the 32-route website, mobile, accessibility, privacy and existing Shield browser suites locally.
- [ ] Verify repository CI and deployed website/Kastro visitor flows for the final commits.

## Before general extension distribution

- [ ] Choose the exact public package/profile/channel, with recorded source identity and checksums.
- [ ] Confirm redistribution rights for each bundled code, dataset and model asset.
- [ ] Complete independent quality acceptance under the [quality contract](detector-quality-contract.md); document current misses and fallback scope.
- [ ] Complete supervised, synthetic-only authenticated ChatGPT/Claude workflow checks for the chosen build.
- [ ] Verify final operator, website-host logging/retention and contact-retention details; review applicable terms and store disclosures.
- [ ] Verify private security and feedback handoff; define realistic maintenance/support capacity without an SLA promise.
- [ ] Test user comprehension of pre-submit draft visibility, warned failure continuation, unchanged attachments, reset and removal.
- [ ] Publish a verified download/store link and reviewed release notes only after the selected channel and artifact are ready.

Use the [distribution process](community-distribution.md). Existing alpha packages remain evaluation previews. Free access does not grant open-source or model/dataset publication rights. Hosted processing remains deferred; any revival requires the original deployment/provider/security controls and fresh authorization. Historical commercial dates, grant deadlines and price books are not active launch prerequisites.
