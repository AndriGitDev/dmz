# Community roadmap

Active direction: [ADR 0005](adr/0005-free-community-project.md), 27 October 2026. [Community concept](community-project.md).

| Stage | Deliverable | Acceptance |
| --- | --- | --- |
| Scope transition | Free DMZ positioning across product, website and Kastro | Both locales, old URLs, metadata, instructions and feedback agree; no price/seat/pilot funnel |
| Preview distribution | Identified package and honest installation/update/removal guidance | Asset rights, build identity and existing regression/browser checks verified; no invented store listing |
| Quality and usability | Fabricated-data testing and independent quality review | Users understand warnings, pre-submit page visibility, unchanged attachments and coverage limits; no regression per entity type |
| Community maintenance | Feedback triage, reviewed results and release notes | Working private security route, no sensitive-data collection, realistic support and maintenance capacity |

There is no promised calendar for general release. The >=99% exact entity-set accuracy and >=99% recall research targets remain unproven; see the [quality contract](detector-quality-contract.md). Development measurements do not establish field quality.

## Next work

Complete the cross-repository positioning pass and verification, then review the actual distribution artifact, redistribution rights and independent quality gap. Existing private alpha packages remain evaluation artifacts. Public store publication is a separate release action, requiring verified disclosures and package evidence.

Portal, Gateway, hosted inference, tenant accounts, server audit exports, certification programmes and Nordic expansion are outside the current release scope. Preserve the scaffold and ADR 0004 for reference. Paid-pilot commitments and MRR are no longer continuation gates. Historical dates and financial assumptions remain in the [business-plan baseline](business-plan.md) and [financial model](financial-model.md); do not treat their past deadlines as current tasks.
