# Error-driven experiment protocol

Objective: improve exact Person precision and recall toward 95.5% each, keeping
all prompt data and model inference local. This is research, not a Shield release.

## Fixed evaluation boundaries

Use only the existing MIM development split for diagnosis and model selection in
this round. The previous MIM test and 40-case domain probe have already been
exposed; neither is opened for further tuning here. Do not treat either as an
independent final evaluation. New independent document-disjoint evaluation awaits
human-reviewed data. Never relabel development records as training records.

The new synthetic v2 supplement has separate training and development template
families and name pools. All data is fabricated, generated by the same agent, and
**unreviewed**. Template repetition/correlated variants limit generalization;
1120 generated documents do not constitute 1120 independent real-world samples.
It is a development stress test and training supplement only. Human review forms
are in `bench/corpus/domain/legal-financial-v2/REVIEW.md`.

## Planned comparisons

1. Reproduce the existing v1 CRF development results and audit exclusive error
   categories plus overlapping name characteristics.
2. CRF with competing Person/Organization/Location/Miscellaneous BIO labels.
3. Original Person-only CRF plus the synthetic training supplement, one copy.
4. Competing-label CRF plus the same supplement, one copy.
5. Frozen pretrained IceBERT with a newly trained BIO Person classifier. Compare
   linear and 128-unit hidden heads, eight epochs each, seed 42, AdamW learning
   rate 0.001, weight decay 0.01. Encoder remains frozen. Inspect all checkpoints
   on development only, preserving unsuccessful results.

CRF comparisons use feature v1, 100 maximum iterations, c1=c2=0.1. Reuse the
fixed confidence threshold grid `0, .5, .6, .65, .7, .75, .8, .9, .95`.
The primary selection rule for this round is: require precision >=95.5% on BOTH
MIM development and synthetic domain development, then maximize the lower of the
two recalls. If no candidate qualifies, report that outcome; do not lower the
precision requirement. This is a selection rule, not a pooled performance metric.
Report both datasets independently with TP/FP/FN and the dual target status.

Changing this bounded experiment list after seeing results must be recorded as a
new development experiment, not presented as a preselected final result.

## IceBERT provenance and limits

Model: [Miðeind IceBERT](https://huggingface.co/mideind/IceBERT), revision
`24c145af7b7d092ecb082897db2e16107301d657`. Model card labels it CC-BY-4.0 and
identifies it as a RoBERTa-base masked language model, not a NER-finetuned model.
Downloaded only safetensors weights, tokenizer/configuration and model card.
No remote code or remote inference is used; embeddings and learned heads remain
outside Git. Retain attribution to Miðeind and Snæbjarnarson et al., 2022,
[A Warm Start and a Clean Crawled Corpus](https://aclanthology.org/2022.lrec-1.464/).
Our derived classifier is experimental and trained locally on the stated mixture.
The encoder runs in float32 on CPU; mean-subword vectors are cached as float16
and converted back to float32 for classifier training. Contexts longer than 256
subwords are split at word boundaries without dropping tokens. Length bucketing
reduces padding; output indices preserve the original sentence/token order.

Its pretraining includes Icelandic web/news/book corpora. Overlap with MIM source
text is not excluded; do not claim uncontaminated held-out language-model exposure.
The final independent corpus must be newly sourced/reviewed. The large Python
encoder is not suitable evidence of browser readiness: package size, memory,
latency, and a local browser inference implementation require separate work.

## Added development experiment after the CRF audit

The augmented model found 117/120 full-form synthetic development names, versus
87/120 initial forms, 102/120 uppercase forms and 94/120 single names. These
are diagnostic subsets, not independent performance estimates. Add one targeted
CRF feature-v3 run (Person labels, same mixture/100 iterations/regularization):
explicit single-letter/initial-before-period, length bucket, hyphen/digit flags,
and uncollapsed case shape in the local context. This comparison was added after
observing the CRF development audit and must not be described as preselected.
It still uses the same threshold grid and final selection rule.

## Added development ensemble after the frozen-head comparison

The fixed rule selects MLP epoch 8 at 0.65 among the 21 standalone candidates.
It gives MIM development P96.67/R90.70 and synthetic-domain P95.74/R88.96.
Add one combination experiment with that frozen head and the feature-v3 CRF.
At each of the same nine CRF thresholds, add neural spans passing each of the
same nine neural thresholds only when they do not overlap a retained CRF span.
CRF priority is fixed before evaluating combinations; scores from different models
are not compared as calibrated probabilities. This makes 81 development trials.
Require the same precision floor on both datasets and maximize the lower recall.
Record this as post-audit development, not an independent validation or a
preplanned standalone comparison. No weights or annotations change.

## Added longer nonlinear-head run after ensemble audit

The epoch-8 ensemble reaches MIM P95.65/R94.89 and synthetic-domain P98.72/R96.04
(CRF 0.75, neural 0.65). Of 77 MIM misses, 35 have no prediction from either
model, 22 are below threshold, 17 have incorrect boundaries and 3 are blocked by
CRF overlap priority. Changing overlap handling alone cannot close the gap.
The nonlinear head's training loss is still declining at epoch 8. Add one run
with the same seed, architecture, optimizer and data for 16 epochs. Verify the
first eight checkpoints reproduce the shorter run. Evaluate epochs 9–16
standalone and combined with the same feature-v3 CRF and fixed 9x9 threshold
grid. Preserve all results. This adds eight standalone and 648 ensemble trials;
selection remains development-only, with no independent-final or release claim.
