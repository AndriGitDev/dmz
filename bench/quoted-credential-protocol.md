# Quoted credential alphabet probe

Frozen before scoring or detector edits on 5 October 2026. This development follow-up is motivated by the retained punctuation and non-ASCII misses in `credential-context-v3`; it is not independent acceptance data.

The proposed extension applies only to a complete balanced single- or double-quoted literal in the existing credential-assignment grammar. Keep the existing minimum 20 bytes, ASCII letter plus digit, empirical byte entropy ≥3.5, key-name policy, uncertainty level and expression/fence handling. Keep unquoted values unchanged. Permit printable non-whitespace punctuation and Unicode within quoted values, except quote, backslash, dollar and backtick characters and double-brace template delimiters. Escapes, interpolation, whitespace, control/format characters and incomplete literals remain unsupported; do not emit a supported prefix. These are explicit heuristics, not provider guarantees or a string-language parser. Byte entropy can overstate diversity in multibyte text; the unchanged ASCII letter/digit condition and separate Unicode probes do not remove that limitation.

The pinned corpus contains 46 fabricated excerpts, 33 labelled credentials and 13 negatives. Twenty-one suffix probes cover punctuation and Unicode, and four cases vary JSON, code, password and quoted assignment contexts. Eight explicit credentials intentionally violate a retained guard and stay positive, including a template-shaped literal. Negatives cover public/metadata fields, references, templates, expressions, malformed syntax and prose. No issuer requests occur.

Record native and packaged baselines before editing the rule. After implementation, measure exact spans, full masking, restoration and false positives on this whole unchanged corpus, then replay the existing nineteen corpora. Keep all failures visible. Do not pool probes into a representative accuracy estimate, retune entropy/length using these results or change the name model. Any existing quality regression requires investigation before accepting the implementation. A verified preview built before this experiment remains valid for its recorded source only.
